Paso a paso

  1. Descarga el zip

    Pulsa «Descargar el zip». Se guarda en tu carpeta Descargas como MasterDev-x.y.z-win-x64.zip. Pesa unos 340 MB.

    MasterDev-x.y.z-win-x64.zip

  2. Descomprímelo en una carpeta tuya

    Clic derecho sobre el zip › «Extraer todo…» y elige una carpeta que no vayas a borrar, por ejemplo Documentos\MasterDev-app. No lo abras desde dentro del zip: tiene que estar extraído.

    MasterDev-…zip
    Abrir Extraer todo… Compartir Copiar como ruta de acceso

  3. Abre MasterDev.exe

    Dentro de la carpeta, doble clic en MasterDev.exe. La primera vez Windows te avisará, porque la app aún no está firmada. Pulsa «Más información» y después «Ejecutar de todos modos». Por qué pasa esto.

¿Por qué Windows te avisa?

Windows muestra «Windows protegió su PC» con cualquier programa nuevo que no tenga firma de código. La firma es un certificado de pago que confirma quién publica el programa. MasterDev es un proyecto indie y todavía no lo tiene.

El aviso no significa que se haya encontrado un virus: significa que Windows aún no conoce el archivo. Para estar tranquilo, descárgalo solo desde esta web o desde el GitHub oficial y comprueba su huella.

Smart App Control

Si tienes Smart App Control activado, Windows bloquea los programas sin firma y no aparece «Ejecutar de todos modos». Puedes comprobarlo en Seguridad de Windows › Control de aplicaciones y navegador. Si está activado, MasterDev no abrirá hasta que esté firmada. Ojo: si lo desactivas, Windows no deja volver a activarlo sin reinstalar.

Comprueba que el archivo es el original

Cada versión publica su huella SHA-256. Si la de tu zip coincide, es exactamente el archivo que se publicó.

  1. Abre PowerShell (busca «PowerShell» en el menú Inicio) y pega este comando:
(Get-FileHash "$env:USERPROFILE\Downloads\MasterDev-x.y.z-win-x64.zip" -Algorithm SHA256).Hash
  1. Debe salir exactamente esta huella (sin importar mayúsculas):
