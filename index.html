03 · DESCARGARDOWNLOAD

Instálalo en un minutoSet it up in a minute

  1. Descarga el zip y descomprímelo en una carpeta tuya (por ejemplo, Documentos\MasterDev-app).Download the zip and unzip it into a folder of yours (for example, Documents\MasterDev-app).
  2. Abre MasterDev.exe. No hace falta instalar nada más.Open MasterDev.exe. Nothing else to install.
  3. Crea tu cuenta local y elige tu camino: creador o jugador.Create your local account and pick your path: creator or player.
  4. Las versiones nuevas llegan solas: la app te avisa y se actualiza con Ctrl + Shift + R.New versions arrive on their own: the app tells you and updates with Ctrl + Shift + R.

[!!] WINDOWS TE AVISARÁWINDOWS WILL WARN YOU

MasterDev es un proyecto indie y todavía no tiene firma de código. La primera vez, Windows mostrará «Windows protegió su PC»: pulsa Más información y luego Ejecutar de todos modos. Si tienes Smart App Control activado, Windows no la dejará abrir hasta que esté firmada.MasterDev is an indie project and isn't code-signed yet. The first time, Windows will show "Windows protected your PC": click More info and then Run anyway. If you have Smart App Control turned on, Windows won't let it open until it's signed.

04 · PREGUNTASQUESTIONS

Preguntas frecuentesFAQ

¿Cuánto cuesta?How much does it cost?

La versión actual se descarga gratis. Las tareas con Claude usan tu propia cuenta de Claude, si decides conectarla.The current version is a free download. Tasks with Claude use your own Claude account, if you choose to connect it.

¿Dónde se guardan mis cosas?Where is my stuff stored?

En tu PC: tus proyectos e ideas en Documentos\MasterDev, y tu cuenta y ajustes en tus datos locales. La Comunidad pasa por un servidor MasterDev, que puedes alojar tú mismo.On your PC: projects and ideas in Documents\MasterDev, account and settings in your local app data. The Community goes through a MasterDev server, which you can host yourself.

¿Hay versión para Mac, Linux o móvil?Is there a Mac, Linux or mobile version?

Por ahora solo Windows. Linux y una versión web de la Comunidad para el móvil están en el plan.Windows only for now. Linux and a web version of the Community for phones are on the roadmap.

¿Qué motores puedo usar?Which engines can I use?

Los que quieras. MasterDev trae plantillas para juegos web (JavaScript, HTML5, Phaser) y Roblox (Luau), y acepta cualquier otro motor por proyecto.Any you like. MasterDev ships templates for web games (JavaScript, HTML5, Phaser) and Roblox (Luau), and accepts any other engine per project.

¿Es seguro si Windows me avisa?Is it safe if Windows warns me?

El aviso sale con cualquier programa nuevo sin firma. Descárgalo solo desde esta página o desde el GitHub oficial; cada versión publica su SHA-256 para que puedas comprobar el archivo.The warning appears for any new unsigned program. Only download it from this page or the official GitHub; every version publishes its SHA-256 so you can check the file.
