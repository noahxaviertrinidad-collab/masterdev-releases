{{es:¿Por qué Windows te avisa?|en:Why does Windows warn you?}}

{{es:Windows muestra «Windows protegió su PC» con cualquier programa nuevo que no tenga firma de código. La firma es un certificado de pago que confirma quién publica el programa. MasterDev es un proyecto indie y todavía no lo tiene.|en:Windows shows “Windows protected your PC” for any new program without a code signature. A signature is a paid certificate that confirms who publishes the program. MasterDev is an indie project and doesn't have one yet.}}

{{es:El aviso no significa que se haya encontrado un virus: significa que Windows aún no conoce el archivo. Para estar tranquilo, descárgalo solo desde esta web o desde el GitHub oficial y comprueba su huella.|en:The warning doesn't mean a virus was found: it means Windows doesn't know the file yet. To be safe, only download it from this site or the official GitHub and check its fingerprint.}}

Smart App Control

{{es:Si tienes Smart App Control activado, Windows bloquea los programas sin firma y no aparece «Ejecutar de todos modos». Puedes comprobarlo en Seguridad de Windows › Control de aplicaciones y navegador. Si está activado, MasterDev no abrirá hasta que esté firmada. Ojo: si lo desactivas, Windows no deja volver a activarlo sin reinstalar.|en:If Smart App Control is on, Windows blocks unsigned programs and “Run anyway” doesn't show up. You can check it in Windows Security › App & browser control. If it's on, MasterDev won't open until it's signed. Careful: if you turn it off, Windows won't let you turn it back on without reinstalling.}}
