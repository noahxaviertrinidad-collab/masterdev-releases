La vista Roblox Studio #

/roblox: todos tus juegos de Roblox en una lista y Studio en vivo. Sin IA puedes revisar el Luau, ver qué módulo usa a cuál, buscar y reemplazar en todo el lugar, insertar módulos probados, dibujar el nivel y construirlo, empezar desde un kit por género y pasar una prueba de humo antes de publicar.

Con Claude #

En los proyectos Luau · Roblox, Claude se conecta a Roblox Studio por MCP si está abierto con el plugin (Ajustes › Roblox Studio). Ves Studio antes y después de cada tarea. Las tareas que no necesitan Studio (documentos, diseño) pueden ir a la vez que una que sí lo usa.

🧱 Roblox Studio

Your Roblox games, from here.

In short: See your Roblox games, create one from a template and let the AI work in Studio with you.

  • The Roblox Studio view
  • With Claude

The Roblox Studio view #

/roblox: all your Roblox games in one list and live Studio. Without AI you can review the Luau, see which module uses which, search and replace across the whole place, insert tested modules, draw the level and build it, start from a kit per genre and run a smoke test before publishing.

With Claude #

In Luau · Roblox projects, Claude connects to Roblox Studio via MCP if it's open with the plugin (Settings › Roblox Studio). You see Studio before and after each task. Tasks that don't need Studio (documents, design) can run at the same time as one that does.
