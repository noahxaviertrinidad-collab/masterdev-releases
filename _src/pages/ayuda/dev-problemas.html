🛟 Si algo no va

Las dudas más comunes.

En corto: Si algo no va (la IA, Roblox Studio o tus proyectos), aquí están los arreglos más comunes.

  • «Claude Code no encontrado»
  • Una tarea se interrumpió
  • Roblox Studio no conecta
  • No veo mis proyectos

«Claude Code no encontrado» #

Instala Claude Code y pulsa «Comprobar de nuevo», o pon su ruta a mano en Ajustes › Claude.

Una tarea se interrumpió #

Si MasterDev se cerró con tareas en marcha, salen como «Interrumpida». Respóndeles para retomarlas: recuerdan lo que llevaban.

Roblox Studio no conecta #

Abre Studio con el plugin de MCP instalado (Ajustes › Roblox Studio) y el lugar del proyecto abierto.

No veo mis proyectos #

MasterDev nunca los borra. Si sale vacío, ciérralo y ábrelo desde el acceso directo del Escritorio: abrirlo desde una terminal o desde otra carpeta puede usar otros datos. También hay una copia de seguridad diaria en Ajustes › Copias de seguridad.

🛟 If something's not working

The most common questions.

In short: If something isn't working (the AI, Roblox Studio or your projects), here are the most common fixes.

  • “Claude Code not found”
  • A task was interrupted
  • Roblox Studio won't connect
  • I can't see my projects

“Claude Code not found” #

Install Claude Code and click “Check again”, or enter its path manually in Settings › Claude.

A task was interrupted #

If MasterDev closed while tasks were running, they show as “Interrupted”. Reply to them to resume: they remember what they were doing.

Roblox Studio won't connect #

Open Studio with the MCP plugin installed (Settings › Roblox Studio) and the project's place open.

I can't see my projects #

MasterDev never deletes them. If it shows empty, close it and open it from the Desktop shortcut: opening it from a terminal or another folder may use different data. There's also a daily backup in Settings › Backups.
