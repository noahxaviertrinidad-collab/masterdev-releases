🛟 Si algo no va

Las dudas más comunes.

En corto: Si algo no va, aquí están los problemas más comunes y cómo arreglarlos.

  • No veo mis juegos
  • No me conecta al servidor
  • No se me oye en la llamada
  • Logros, Discord o mods
  • No veo mis cosas (amigos, listas, ajustes)

No veo mis juegos #

Pulsa Reescanear en la Biblioteca del Centro. MasterDev mira Steam, Epic, Xbox, Microsoft Store y Roblox; si un juego está en otro lanzador, puede que no lo encuentre.

No me conecta al servidor #

  • Comprueba que quien lo aloja lo tiene abierto y con «Permitir conexiones desde la red local».
  • Si Windows pregunta por el firewall al abrir MasterDev o el servidor, di que sí.
  • Desde fuera de casa hace falta un servidor en internet (un VPS) o una invitación de alguien que lo tenga.

No se me oye en la llamada #

Mira que Windows deja usar el micro a MasterDev (Configuración › Privacidad › Micrófono). Si tienes pulsar para hablar, el micro solo se abre mientras mantienes tu tecla.

Logros, Discord o mods #

  • «Tu perfil de Steam no deja ver los logros»: pon «Detalles de juegos» en Público en la privacidad de tu perfil de Steam.
  • Discord no cambia: Discord tiene que estar abierto en este PC y el Application ID tiene que ser de una aplicación tuya. En Ajustes › Interfaz › Discord ves el estado.
  • Los mods no salen en Minecraft: abre Minecraft con el perfil del mismo cargador y versión que elegiste en Juegos › Mods.

No veo mis cosas (amigos, listas, ajustes) #

MasterDev nunca borra tus datos. Si de pronto sale vacío, ciérralo y ábrelo desde el acceso directo del Escritorio: abrirlo desde otro sitio puede usar otra carpeta de datos.

🛟 If something's not working

The most common questions.

In short: If something isn't working, here are the most common problems and how to fix them.

  • I can't see my games
  • I can't connect to the server
  • I can't be heard on the call
  • Achievements, Discord or mods
  • I can't see my stuff (friends, lists, settings)

I can't see my games #

Click Rescan in the Library on Home. MasterDev looks in Steam, Epic, Xbox, Microsoft Store and Roblox; if a game is in another launcher, it may not find it.

I can't connect to the server #

  • Check that whoever hosts it has it open and with “Allow connections from the local network” turned on.
  • If Windows asks about the firewall when opening MasterDev or the server, say yes.
  • From outside home you need a server on the internet (a VPS) or an invite from someone who has one.

I can't be heard on the call #

Make sure Windows lets MasterDev use the microphone (Settings › Privacy › Microphone). If you use push to talk, the mic only opens while you hold your key.

Achievements, Discord or mods #

  • “Your Steam profile doesn't let achievements be seen”: set “Game details” to Public in your Steam profile privacy settings.
  • Discord doesn't change: Discord has to be open on this PC, and the Application ID must belong to one of your apps. In Settings › Interface › Discord you can see the status.
  • Mods don't show up in Minecraft: open Minecraft with the profile for the same loader and version you chose in Games › Mods.

I can't see my stuff (friends, lists, settings) #

MasterDev never deletes your data. If it suddenly shows empty, close it and open it from the Desktop shortcut: opening it from somewhere else may use a different data folder.
