Roblox Studio

Your Roblox games, all in one place

MasterDev's Roblox Studio view gathers your games even if they aren't MasterDev projects, helps you start a new one and lets you watch Studio live. It doesn't need Claude.

Available

All your games

What you've opened in Studio on this PC, your public games and your Luau projects, each with its icon and a button to open it in Studio. Search and filter by “On Roblox”, “Files” or “Projects”.

Available

Create from a template

Name it and pick a template: Baseplate, the MasterDev structure (server, client and module ready to go) or empty. You can register it as a project and open it in Studio right away.

Available

Studio live

With Studio open and its MCP plugin connected, you see the Explorer, properties, scripts, the Output and a viewport capture. It's read-only: it changes nothing.

Optional · with Claude

Claude inside Studio

In tasks for a Luau project, MasterDev connects the Roblox Studio MCP server on its own. Claude can then see the game tree, read and edit scripts, create parts, press Play, read the console and take captures in the Studio you have open.

If no Studio is open, Claude tells you and doesn't make up changes. In “plan” mode it only analyzes and proposes, without touching Studio.

Before you start

  • Open Roblox Studio with your place and the MCP plugin connected.
  • Save your place as usual: Claude can modify it, and Roblox's version history is your safety net.
  • You can turn the connection off in Settings › Roblox Studio (MCP).

Open your game without hunting for it

  1. In the project page, paste the game link, the creator dashboard link or the place number. A .rbxl file works too.
  2. Click ◆ Roblox Studio. If it's already open, MasterDev brings its window to the front instead of opening another copy.
