🎮 Projects

Your games: new ones or ones you already have.

In short: Every game is a project. Create a new one or link the one you already have; its page and its Studio keep everything about the game.

  • Create a new one
  • Link one you already have
  • The project's Studio
  • Sheet and documents

Create a new one #

  1. + New project in In the app: Projects.
  2. Name and genre, engine (yours first), style and resolution, and the key mechanics.
  3. Create with Claude: generates the GDD and the boilerplate. Web games (HTML5, Phaser) are played inside MasterDev with ▶ Play.

Link one you already have #

/link (or 🔗 Link existing project) registers a folder you already have. It doesn't copy or move anything. That project's tasks run inside its folder and follow its own CLAUDE.md, skills and permissions. Unlinking only removes it from MasterDev.

The project's Studio #

Each project has its Studio tab: draw the core loop, tune the balance with formulas and a chart, write branching dialogue, organize a board, log bugs and prepare the devlog, the press kit and the store page. Claude receives all of that in its tasks.

Sheet and documents #

⚙ Edit project sheet: status, engine, the game's color and icon (it tints MasterDev while you work on it), rules for Claude and extra permissions. Under Documents you choose which .md to view (README, TAREAS.md, docs/…).
