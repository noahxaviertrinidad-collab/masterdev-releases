Step by step

  1. Download the zip

    Click “Download the zip”. It's saved to your Downloads folder as MasterDev-x.y.z-win-x64.zip. It's about 340 MB.

    MasterDev-x.y.z-win-x64.zip

  2. Unzip it into a folder of yours

    Right-click the zip › “Extract All…” and choose a folder you won't delete, for example Documents\MasterDev-app. Don't open it from inside the zip: it has to be extracted.

Why does Windows warn you?

Windows shows “Windows protected your PC” for any new program without a code signature. A signature is a paid certificate that confirms who publishes the program. MasterDev is an indie project and doesn't have one yet.

The warning doesn't mean a virus was found: it means Windows doesn't know the file yet. To be safe, only download it from this site or the official GitHub and check its fingerprint.

Smart App Control

If Smart App Control is on, Windows blocks unsigned programs and “Run anyway” doesn't show up. You can check it in Windows Security › App & browser control. If it's on, MasterDev won't open until it's signed. Careful: if you turn it off, Windows won't let you turn it back on without reinstalling.

Check that the file is the original

Every version publishes its SHA-256 fingerprint. If your zip's matches, it's exactly the file that was published.

  1. Open PowerShell (search “PowerShell” in the Start menu) and paste this command:
(Get-FileHash "$env:USERPROFILE\Downloads\MasterDev-x.y.z-win-x64.zip" -Algorithm SHA256).Hash
