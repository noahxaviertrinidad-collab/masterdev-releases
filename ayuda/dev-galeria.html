🖼 Galería y clips

Las capturas y los vídeos de cualquier juego del PC, y de los tuyos: captúralos, ordénalos por proyecto, edítalos, crea material para la tienda y compártelos.

En corto: Captura y graba tu juego, edita las imágenes y prepara material para tu tienda o tus redes.

Capturar y grabar #

  • Ctrl+Alt+S captura el juego de delante, Ctrl+Alt+G graba y, con la repetición encendida, Alt+F10 guarda los últimos segundos. Las capturas de Steam, la Barra de juego, NVIDIA y OBS llegan solas, con su juego.
  • Menú 📸 de la Galería: retardo, una zona o ventana guardada (con su atajo, «Captura del encuadre»), una captura grande de 4K u 8K de tu juego web y 📷 Studio. Una captura con Roblox Studio delante guarda el lugar y la cámara: 🎥 Volver a esta vista la deja igual en Studio.
  • Al grabar: tu cámara en una esquina, vertical o 1:1, solo audio, capítulos 🔖 y «⏺ Grabar el playtest», que espera en Edit, graba al pulsar Play en Studio y para al volver.

Ordenar y buscar #

  • La En la app: Galería va por línea de tiempo y cada proyecto tiene su pestaña Galería en la ficha. El visor compara dos capturas (p. ej. dos builds) con el zoom a la vez y enseña sus datos (ℹ), también la build.
  • Busca por el texto de la imagen, por color (🎨, comparado con la paleta de tu proyecto) o, si lo enciendes en ⚙, por lo que describe tu IA (apagado de serie: se cobra). Ponle la etiqueta bug a una captura y crea el bug en el Estudio con su imagen.

El editor #

  • ✏ Editar: capas (texto, pegatina, flecha, pixelar), deshacer de 50 pasos, filtros CRT, líneas, viñeta, grano y curvas, y tus LUT .cube. Cada guardado es una versión (🕘) y vuelves al original cuando quieras.
  • Para pixel art: amplía ×2 o ×4 sin suavizado, recolorea con la paleta del proyecto (cubo y cuentagotas), quita el fondo de un sprite de fondo liso y «Guardar como sprite» recortado. Para fotos, 🔍 Ampliar usa Real-ESRGAN con tu tarjeta gráfica (se descarga la primera vez, con permiso).
  • Editar en lote (recorte, tamaño y formato a la vez, con recetas guardadas) y un editor de GIF con ida y vuelta y peso objetivo.

Crear para tu juego #

✨ Crear junta 7 herramientas: hoja de sprites (PNG + JSON, y en proyectos Luau un .lua con los rectángulos), collage «el mismo sitio en 4 builds», cápsula de Steam o miniatura de Roblox con tu logo y tu color, póster A4 en PNG o PDF, kit de prensa en ZIP, devlog con plantilla y la paleta de tus capturas en .gpl, .ase o .hex (a tu identidad del Estudio). «Al tablero» las lleva a las referencias, y «🖼 Usar como…» las pone de banner o de fondo.

Clips para tu juego #

  • En la app: Clips junta grabaciones, repeticiones, clips del Navegador (hasta 5 minutos), llamadas y los momentos de tus testers (pulsan F1–F12 en un playtest). Por juego, con título, descripción, miniatura y colecciones que se abren seguidas en el editor.
  • El editor de clips tiene pistas de vídeo, audio, texto y música, cortar y unir, cámara lenta, congelar, zooms, transiciones y «Cortar en trozos» por capítulos. 📱 reencuadra a 9:16 siguiendo la acción, 🎵 añade música avisando de la licencia y 🎙 narra con tu voz o la de Windows.
  • ⋯ Más manda un clip a una idea, como GIF al GDD (sección Arte), a una carta animada o a Estudio › Game feel. Para Discord, comprime a 8, 25 o 50 MB. Sin ffmpeg, MasterDev te ofrece instalarlo.

Compartir #

  • 📤 Compartir: Publicar en… X, Bluesky, Reddit o Discord con el formato de cada uno, copiar para el chat, enlace que caduca (con contraseña, revocable en «Mis enlaces»), marca de agua y sin metadatos ocultos.
  • ¿Cuál es mejor? crea una encuesta con varias capturas; 🌐 En Descubrir pone hasta 8 en la página de tu juego, y un clip puede ser el vídeo de su portada. Tus testers y amigos comentan un clip en el segundo exacto.
  • 📱 Móvil: un QR para ver la Galería o mandar fotos desde el móvil en tu wifi (pulsa «Permitir» solo en redes privadas; se apaga a los 30 min). La nube sube lo que digan tus reglas y 🗂 OneDrive y Google Drive copia una carpeta o un álbum a tu carpeta de OneDrive o Google Drive.

Modo foto #

En tu juego web (▶ Jugar), 📷 Modo foto en la consola del juego lo pausa, esconde el HUD, mueve la cámara con las flechas o WASD y captura a la resolución del canvas (o ×2) con la etiqueta modo-foto. Esc lo deja todo como estaba.

En Roblox no se mete nada en tu juego: copia este ModuleScript en ReplicatedStorage (o pide a Claude en una tarea del proyecto que lo añada por el MCP). P entra y sale, clic derecho gira la cámara, WASD y Q/E la mueven, y Ctrl+Alt+S captura.

-- ReplicatedStorage › PhotoMode (ModuleScript)
local Players = game:GetService("Players")
local RunService = game:GetService("RunService")
local UIS = game:GetService("UserInputService")
local CAS = game:GetService("ContextActionService")
local StarterGui = game:GetService("StarterGui")

local PhotoMode = { speed = 24 }
local conn, saved, hidden = nil, nil, {}

local function setHud(visible)
	pcall(StarterGui.SetCoreGuiEnabled, StarterGui, Enum.CoreGuiType.All, visible)
	local gui = Players.LocalPlayer:FindFirstChildOfClass("PlayerGui")
	if visible then
		for g in hidden do g.Enabled = true end
		table.clear(hidden)
	elseif gui then
		for _, g in gui:GetChildren() do
			if g:IsA("ScreenGui") and g.Enabled then hidden[g] = true; g.Enabled = false end
		end
	end
end

function PhotoMode.toggle()
	local cam = workspace.CurrentCamera
	if conn then
		conn:Disconnect(); conn = nil
		CAS:UnbindAction("PhotoModeSink")
		UIS.MouseBehavior = Enum.MouseBehavior.Default
		cam.CameraType, cam.CFrame = saved.type, saved.cf
		setHud(true)
		return false
	end
	saved = { type = cam.CameraType, cf = cam.CFrame }
	cam.CameraType = Enum.CameraType.Scriptable
	setHud(false)
	local K = Enum.KeyCode
	CAS:BindActionAtPriority("PhotoModeSink", function() return Enum.ContextActionResult.Sink end,
		false, Enum.ContextActionPriority.High.Value + 1, K.W, K.A, K.S, K.D, K.Q, K.E, K.Space)
	local rx, ry = cam.CFrame:ToOrientation()
	conn = RunService.RenderStepped:Connect(function(dt)
		if UIS:IsMouseButtonPressed(Enum.UserInputType.MouseButton2) then
			UIS.MouseBehavior = Enum.MouseBehavior.LockCurrentPosition
			local d = UIS:GetMouseDelta()
			ry -= d.X * 0.004
			rx = math.clamp(rx - d.Y * 0.004, -1.4, 1.4)
		else
			UIS.MouseBehavior = Enum.MouseBehavior.Default
		end
		local move = Vector3.zero
		if UIS:IsKeyDown(K.W) then move += Vector3.new(0, 0, -1) end
		if UIS:IsKeyDown(K.S) then move += Vector3.new(0, 0, 1) end
		if UIS:IsKeyDown(K.A) then move += Vector3.new(-1, 0, 0) end
		if UIS:IsKeyDown(K.D) then move += Vector3.new(1, 0, 0) end
		if UIS:IsKeyDown(K.E) then move += Vector3.new(0, 1, 0) end
		if UIS:IsKeyDown(K.Q) then move += Vector3.new(0, -1, 0) end
		local rot = CFrame.fromOrientation(rx, ry, 0)
		cam.CFrame = rot + cam.CFrame.Position + rot:VectorToWorldSpace(move) * PhotoMode.speed * dt
	end)
	return true
end

return PhotoMode
